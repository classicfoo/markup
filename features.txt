# Screenshot Markup feature checklist

## Image input and output
- Paste images from the clipboard (Ctrl+V).
- Open images from a file picker (Ctrl+L), by dropping a file, or with a path argument.
- Accept PNG, JPEG, GIF, BMP, TIFF, and WebP images.
- Save composed results as PNG or JPEG (Ctrl+S); remember the last format.
- Copy the composed image to the clipboard (Ctrl+C).

## Image enhancement
- Toggle the drop shadow from the toolbar, View menu, or image context menu.
- Start with 13x13 offset, grey color, blur radius 8, white background, and 20px padding.
- Configure offset, blur, padding, shadow color, and background color.
- Add the light grey border around the image when shadow is enabled.

## Markup tools
- Highlighter draws translucent yellow rectangles (50% opacity).
- Redaction draws solid black rectangles.
- Color picker reports pixel coordinates, RGB, and hex values, with copy buttons.
- Text tool adds red Arial text, permits dragging, and edits text on double-click.
- OCR tool selects a region and extracts text through Tesseract.
- OCR results are editable, report selected character count, support the original case transformations, and can be copied.
- Select tools from the toolbar, Tools menu, or image context menu.

## Editing and windowing
- Undo and redo markup or text changes, retaining up to 20 undo states.
- Show a crosshair over the canvas and a move cursor over text overlays.
- Scroll the canvas for large images and resize the initial window to fit the image where possible.
- Open additional app windows from the context menu or Ctrl+N.

## Keyboard shortcuts
- Ctrl+V: Paste image.
- Ctrl+C: Copy composed image.
- Ctrl+S: Save image.
- Ctrl+L: Load image.
- Ctrl+N: Open a new window.
- Ctrl+Z: Undo.
- Ctrl+Y: Redo.

## Preferences and errors
- Save output format and shadow settings in the user's config directory.
- Report invalid image, save, clipboard, and OCR errors in the app.
- OCR requires Tesseract installed separately or configured with `TESSERACT_CMD`.
